# 七年四班 · 班级空间（前端 Demo）

纯静态，无依赖，无后端。双击 `auth.html` 或把它部署为默认首页即可。

## 文件

| 文件 | 说明 |
|---|---|
| `auth.html` | 登录 / 注册（入口页） |
| `auth.css` | 登录注册样式（科幻科技风） |

| `manage.js` / `manage.css` | 行内管理：等级权限、成员、公告、审核、高管设置 |

## 管理中枢（前端演示）

验证通过后**不进入独立后台**，直接回到主界面，按等级在页面上获得权限。

### 进入方式

| 等级 | 路径 | 账号 / 密钥 |
|---|---|---|
| 中级管理 | 首页「管理」→ 诱饵控制台**右上角 7 下 → 左下角 4 下** | `温泊` / `2991` |
| 高级管理 | 中级管理登录后，**长按**右上角「中管」图标打开菜单；**10 秒内短点该图标 11 次** → 高级密钥页 | `温泊` / `7413` |

- 诱饵控制台：终端输入任何指令都显示执行成功，不产生操作
- 手势**没有任何点位/光圈提示**，点对为止
- 核验动画结束后自动 `location.replace('index.html')`，主站右上角出现「中管 / 高管」徽章

### 权限

| 能力 | 普通管理 | 中级管理 | 高级管理 |
|---|---|---|---|
| 删除动态 / 公告 | ✅ | ✅ | ✅ |
| 禁言成员 | ✅ | ✅ | ✅ |
| 删除成员 | ✅ | ✅ | ✅ |
| 修改成员资料 | ❌ | ✅ | ✅ |
| 任命普通管理 | ❌ | ✅ | ✅ |
| 发公告 / 置顶 | ❌ | ✅ | ✅ |
| 审核申请（公告/置顶/寻人） | ✅ | ✅ | ✅ |
| 封禁成员 | ❌ | ❌ | ✅ |
| 高管设置（改两级密钥 / 清空区域） | ❌ | ❌ | ✅ |

- 普通管理由中级/高级在「成员管理 → 成员详情」里任命，被任命者登录后自动获得普管权限
- 普通成员可提交「发公告 / 置顶消息 / 寻人启事」申请，由普通管理优先审核
- 长按「中管 / 高管」徽章 = 打开管理中心；短点不弹菜单
- 高管设置改密钥需要**先输入两个旧密钥**；清空区域需要二次确认

演示账号：`2404-01` / `123456`（温泊）。数据存 `localStorage.c74_admin_v1`，由 `store.js` 统一读写。

> 纯前端形式，密钥和权限都存在本机，**不是真实权限控制**；接 Cloudflare Workers 后由服务端校验并存哈希。

## 注册码机制（演示版）

- 注册码格式：**3 段 × 4 位**字母数字，例：`7C4A-9F2E-B615`
- 输入满 3 段后自动校验，校验通过后固定输入框（改任意一段会重新校验）
- 演示码：`7C4A-9F2E-B615`（普通成员）、`M4D1-77AB-C0DE`（管理员）
- 演示模式下，**格式正确的任意码**也会通过，方便走流程

## 登录（演示版）

- 任意「学号/昵称 + 6 位以上密码」都能进入
- 已注册账号会校验密码（密码存在 localStorage，仅供演示）
- 登录成功写入 `sessionStorage.c74_session`，跳转 `index.html`
- 主界面右上角「退出」会清 session 并回登录页

## 接后端时改哪里

全部集中在 `auth.js` 顶部的 `API` 对象，三个 Promise 函数：

```js
API.verifyCode(code)        // → { ok, data:{use,batch,tags}, error }
API.register({code,name,id,pwd})  // → { ok, data:{name,id}, error }
API.login(id, pwd)          // → { ok, data:{id,name,role}, error }
```

换成 `fetch('/api/...')` 即可，UI、校验、动画逻辑都不用动。
建议后端校验点：注册码是否有效 / 是否已用 / 是否过期、学号唯一性、密码强度与哈希。

## 入口与访问控制（前端层）

- 部署时把 **`auth.html` 设为默认首页**（Netlify/CF Pages 里配 redirect `/ → /auth.html`）
- `index.html` 开头有会话校验：`sessionStorage.c74_session` 为空会 `location.replace('auth.html')`，直接输网址进不去
- 注意 `sessionStorage` 是**按标签页**的：新开标签页需要重新登录。要「记住我」跨标签/跨天，把 `auth.js` 里的存储换成带过期时间的 `localStorage` 即可
